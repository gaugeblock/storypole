# SP-54 - order a handoff by its own clock

## Intent
A handoff must sort by when it was recorded, so records replay agrees with a legacy ledger's file
order and `migrate` can archive that ledger.

## Steps
1. Read `HandoffRecorded` from `handoff.timestamp_ms` in `tickets::order::timestamp_of`.
   Gate: `cargo test -p storypole-core --lib order_tests`
2. Pin it with a regression test that fails when the arm returns zero.
   Gate: mutation check, then `cargo test -p storypole-core`
3. Keep the crate gates clean.
   Gate: `cargo fmt --check`, `cargo clippy --all-targets` rc=0
